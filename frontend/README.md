# Frontend

Interfaz web construida con Next.js, React y TypeScript.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000). Configura la URL de la API en `NEXT_PUBLIC_API_URL` dentro de `.env`.

## Comandos

- `npm run dev`: servidor de desarrollo.
- `npm run build`: compilación de producción.
- `npm start`: sirve la compilación de producción.
